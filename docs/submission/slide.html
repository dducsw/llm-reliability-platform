CODE SNAPSHOT

Theo dõi thay đổi
theo thời gian thực.

Ví dụ minh họa MongoDB Change Streams. Bổ sung xử lý lỗi, retry và cấu hình telemetry trước khi triển khai production.

monitor.js
const stream = db
  .collection("events")
  .watch();

stream.on("change", change => {
  publishMetric(
    "app.db.change",
    1,
    {
      service: "orders-api",
      operation: change.operationType
    }
  );
});
